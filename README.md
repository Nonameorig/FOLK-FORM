# FOLK & FORM — демонстрационный макет сайта

> ⚠️ **Важно:** это учебный/демонстрационный проект. Салон **не существует**, все данные вымышлены. Сайт создан для показа концепции дизайна и вёрстки, а не для реального бизнеса.

---

## О проекте

**FOLK & FORM** — концепт одностраничного сайта для городской студии стрижек и окрашивания среднего ценового сегмента. Проект демонстрирует современный подход к дизайну: сдержанная палитра, кастомная типографика, плавные анимации, адаптивная вёрстка.

## Что это не

- ❌ Не реальный бизнес
- ❌ Не коммерческий продукт
- ❌ Не форма записи (данные не отправляются)
- ❌ Не содержит реальных цен, отзывов, адресов

## Что это

- ✅ Демонстрация концепции дизайна
- ✅ Пример вёрстки лендинга
- ✅ Учебный проект по фронтенду
- ✅ Портфолио-кейс

---

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (Grid, Flexbox, кастомные свойства, анимации)
- Vanilla JavaScript (без фреймворков)
- Google Fonts — **Cormorant** (заголовки) + **Jost** (текст)
- Font Awesome 6.5.1 — иконки
- Unsplash — демонстрационные фотографии
